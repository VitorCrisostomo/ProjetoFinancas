Como instalar e rodar na sua máquina:

Pré-requisitos:
- [Python 3.x](https://www.python.org/)
- [Node.js](https://nodejs.org/)

Instalação Automática:

**Se você usa Windows:**
Dê dois cliques no arquivo `setup.bat` (ou rode `setup.bat` no terminal).

**Se você usa Mac/Linux:**
Abra o terminal na pasta do projeto e rode:
`make install`

Como rodar o projeto:

1. **Backend:** 
   Abra um terminal e ative o ambiente virtual:
   - Windows: `venv\Scripts\activate`
   - Mac/Linux: `source venv/bin/activate`
   - Em seguida rode: `python main.py`

2. **Frontend:**
   Abra outro terminal (na pasta do frontend) e rode:
   `npm run dev`
